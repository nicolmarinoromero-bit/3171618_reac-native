# 📊 Portafolio de Proyectos – AuditApp (Empresa de Auditoría)

## 🏛️ Mi dominio: Empresa de Auditoría

Una empresa de auditoría necesita gestionar sus **auditorías**, **clientes**, **auditores**, **hallazgos** y **estados** de los procesos. Los proyectos de este portafolio simulan aplicaciones móviles (con React Native y Expo) que cubren desde la visualización básica de tarjetas hasta dashboards interactivos y sistemas de configuración.
