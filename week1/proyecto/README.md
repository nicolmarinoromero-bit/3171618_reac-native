# 📋 Auditoría App – Semana 1

## 🏛️ Mi dominio: Empresa de Auditoría

La aplicación muestra una lista de **auditorías** realizadas por una empresa de auditoría. Cada tarjeta representa una auditoría diferente y permite visualizar información clave como:

- **Cliente** auditado y su industria
- **Auditor** responsable
- **Fecha** de la auditoría
- **Número de hallazgos** encontrados
- **Estado** actual (Pendiente / En progreso / Completada)

Al presionar cualquier tarjeta, se muestra una alerta con todos los detalles de la auditoría.

## 🎯 ¿Qué permite hacer la app?

- **Visualizar auditorías** en una lista tipo tarjeta.
- **Consultar detalles completos** de cada auditoría mediante una acción táctil (Pressable).
- **Feedback visual** al presionar cada tarjeta (cambio de opacidad).
- **Organización clara** con imágenes representativas, textos con estilos diferenciados y badges de estado coloreados.

## 📱 Tecnologías utilizadas

- React Native (Expo)
- TypeScript (tipado estricto)
- Flexbox (layout responsivo)
- Core Components: `View`, `Text`, `Image`, `Pressable`, `FlatList`, `SafeAreaView`
